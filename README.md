# 🛍️ سوق البراندات (Souq Brands) | منصة المتاجر والتسوق بالاشتراك الرمزي

منصة تجارة إلكترونية وماركت بليس متكامل يربط بين أصحاب المشاريع والبراندات المستقلة وبين المتسوقين عبر الإنترنت، قائم على نموذج **الاشتراك الرمزي الميسر**.

---

## 💡 فكرة المشروع الأساسية (The Core Concept)
بدلاً من أن يتحمل صاحب البراند أو الشخص الذي يمتلك منتجات تكاليف باهظة لإنشاء وتطوير واستضافة موقع إلكتروني مستقل (التي قد تتجاوز آلاف الجنيهات):
1. **يقوم البراند أو التاجر بالاشتراك في المنصة برسم اشتراك رمزي شهري بسيط** (يبدأ من 149 ج.م شهرياً).
2. **يتم تفعيل متجر إلكتروني مخصص لبرانده فورياً** برابط مباشر، شعار، غلاف، ونبذة تعريفية.
3. **يرفع منتجاته مع الصور، الأسعار، والمخزون** عبر لوحة تحكم التاجر السهلة.
4. **يدخل الزبائن والعملاء أونلاين** لتصفح البراندات والمنتجات، وطلب الشراء مباشرة إما عبر المنصة (الدفع عند الاستلام أو المحافظ الإلكترونية) أو التواصل الفوري عبر الواتساب المباشر للبراند.

---

## ✨ المميزات الرئيسية للمنصة

### 1. تجربة المتسوق والعميل (Shopper Experience):
- **تصفح دليل البراندات (Brands Directory):** استكشاف المتاجر المسجلة مع شارات التوثيق (VIP ماسي، براند ذهبي، بائع معتمد)، تقييمات الزبائن، والنبذة.
- **صفحة متجر مستقلة لكل براند (Dedicated Brand Storefront):** تصفح منتجات براند معين بالكامل والتواصل معه.
- **سوق المنتجات والتصنيفات (Product Explorer):** فلاتر سريعة حسب التصنيف، البراند، السعر، العروض الترويجية، وحالة التوفر.
- **معاينة المنتج السريعة (Quick View Modal):** معرض صور عالي الدقة، جدول المواصفات، وحساب الخصم.
- **سلة التسوق الذكية (Smart Cart Drawer):** تعديل الكميات مع شريط إشعار الشحن المجاني.
- **إتمام الطلب (Checkout):** إدخال بيانات التوصيل واختيار طريقة الدفع:
  - الدفع عند الاستلام (Cash on Delivery).
  - فودافون كاش / انستاباي / محافظ الهاتف (Vodafone Cash / InstaPay).
  - بطاقة بنكية (Visa / Mastercard).
- **تتبع الطلبات الفوري (Live Order Tracking):** إدخال رقم الطلب لمعرفة خط سير الشحنة مرحلة بمرحلة (تم الاستلام -> قيد التجهيز من البراند -> مع المندوب -> تم التسليم).
- **طلب فوري عبر واتساب التاجر بنقرة واحدة.**

### 2. نظام اشتراك البراندات بالرسوم الرمزية (Nominal Subscriptions):
- **باقة الانطلاقة (Starter Plan):** 149 ج.م شهرياً ($5) - حتى 15 منتج، عمولة 5%، شارة بائع معتمد.
- **باقة البراند الصاعد (Pro Brand Plan):** 299 ج.م شهرياً ($10) [الأكثر طلباً] - حتى 70 منتج، عمولة 2%، شارة ذهبية، أولوية ظهور.
- **باقة الشركات والـ VIP (Enterprise VIP):** 599 ج.م شهرياً ($20) - منتجات غير محدودة، 0% عمولة، شارة ماسية، دعم VIP.
- **محاكاة سداد الرسوم الرمزية وتفعيل المتجر فوراً.**

### 3. لوحة تحكم التاجر / صاحب البراند (Vendor Dashboard):
- إحصائيات المبيعات، الطلبات الواردة، ونسبة استهلاك سعة المنتجات.
- بطاقة حالة الاشتراك وتاريخ التجديد وعدد الأيام المتبقية مع زر تجديد أو ترقية الباقة.
- إضافة وتعديل وحذف المنتجات مع تحديد الأسعار والخصومات والمخزون.
- إدارة وتحديث حالات الطلبات الواردة (قيد المراجعة، قيد التجهيز، تم الشحن، تم التسليم).
- زر مباشر لمراسلة العميل صاحب الطلب عبر واتساب.

### 4. لوحة إدارة المنصة (Platform Admin):
- إجمالي أرباح المنصة المحصلة من الاشتراكات الرمزية الشهرية للبائعين.
- إجمالي حجم المبيعات (GMV) وإحصائيات المتاجر والمنتجات.
- استعراض وتدقيق جميع المتاجر المسجلة.

### 5. التقنيات والواجهة:
- دعم كامل للغة العربية (RTL) مع إمكانية التبديل للإنجليزية (LTR).
- تبديل العملات (ج.م EGP / $ USD / ر.س SAR).
- حفظ واسترجاع كامل البيانات عبر LocalStorage دون فقدان أي متجر أو منتج أو طلب جديد يتم إنشاؤه.
- بناء سريع وواجهة عصرية باستخدام React, Vite, Tailwind CSS, Lucide Icons.

npm run build
